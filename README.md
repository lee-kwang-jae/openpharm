# 연휴 약국·병원 찾기 (holiday-care)

공휴일·연휴에 문 여는 약국과 병·의원을 **동 이름으로** 찾아보는 앱인토스 미니앱이에요.
지도와 목록을 함께 보여주고, 날짜를 골라 그날의 운영 여부를 확인할 수 있어요.

## 서비스 지역

현재 **6,000곳 · 73개 동**을 담고 있어요.

| 지역 | 시설 | 동 | 청크 |
| --- | ---: | ---: | ---: |
| 서울특별시 송파구 | 1,711 | 13 | 337KB |
| 경기도 성남시 분당구 | 1,362 | 15 | 243KB |
| 서울특별시 강동구 | 1,239 | 13 | 238KB |
| 경기도 성남시 수정구 | 655 | 12 | 111KB |
| 경기도 하남시 | 598 | 12 | 107KB |
| 경기도 성남시 중원구 | 435 | 8 | 68KB |

청크는 선택한 지역 것만 `import()`로 불러오니, 한 번에 최대 337KB만 로드돼요.

범위는 [`scripts/coverage.mjs`](scripts/coverage.mjs) 에서 바꿉니다.

```js
export const COVERAGE = [
  { sido: '경기도', sigungu: '하남시' },
  { sido: '서울특별시', sigungu: '송파구' },
  // "성남시"처럼 상위 시 이름만 적으면 수정구·중원구·분당구가 모두 포함돼요.
  { sido: '경기도', sigungu: '성남시' },
];
```

고친 뒤 `npm run sync:data` 를 다시 돌리면 돼요.
전국 원본이 `.cache/` 에 저장돼 있어서 **API 호출 없이** 즉시 반영됩니다.
한 번만 써보고 싶으면 환경변수로도 돼요.

```bash
SYNC_REGIONS="경기도 하남시,서울특별시 강동구" npm run sync:data
```

## 준비물

### 1. 공공데이터포털 서비스 키

[data.go.kr](https://www.data.go.kr) 로그인 후 아래 API에 **활용신청**하세요 (개발계정은 자동승인).

| API | 용도 |
| --- | --- |
| 국립중앙의료원\_전국 약국 정보 조회 서비스 | 약국 목록·운영시간 |
| 국립중앙의료원\_전국 병·의원 찾기 서비스 | 병·의원 목록·운영시간 |
| 한국천문연구원\_특일 정보 | 공휴일 목록 (선택, 없으면 기본값 사용) |

승인되면 `마이페이지 > 오픈API > 인증키`의 **Encoding 키**를 복사하세요.

### 2. 카카오맵 JavaScript 키

[앱 관리 페이지](https://developers.kakao.com/console/app)에서 앱을 고른 뒤, 지도가 뜨려면
**두 가지**를 모두 해야 합니다. 하나만 해도 지도는 안 뜨고 기본 지도(OpenStreetMap)로 대체돼요.

1. `[카카오맵] > [사용 설정]`의 `[상태]`를 **ON**
   - 카카오맵 무료 쿼터는 개발자 계정에서 **가장 먼저 활성화한 앱 1개**에만 붙습니다.
     두 번째 앱부터는 비즈월렛 연결 + 유료 API 설정이 필요해요.
2. `[앱] > [플랫폼 키] > [JavaScript 키]`를 열어 `[JavaScript SDK 도메인]`에 아래를 모두 등록

```
http://localhost:5173
http://localhost:4173
https://kjnewsletter.github.io
```

설정을 마쳤으면 아래 명령으로 확인하세요. 어느 쪽이 빠졌는지 짚어줍니다.

```bash
npm run check:kakao
```

> 브라우저는 카카오 SDK 응답을 CORS 때문에 읽을 수 없어서, 앱 화면에서는 "지도를
> 불러오지 못했어요"까지만 알 수 있어요. 사유는 이 명령으로 확인합니다.

### 3. `.env` 작성

```bash
cp .env.example .env
```

`.env`를 열어 두 값을 채웁니다. `.env`는 `.gitignore`에 있어서 커밋되지 않아요.

## 실행

```bash
npm install
npm run sync:data   # 공공데이터를 내려받아 src/data/ 에 스냅샷 생성 (몇 분 소요)
npm run dev         # http://localhost:5173
```

## 데이터 구조

런타임에는 API를 호출하지 않아요. 빌드 전에 스냅샷을 떠서 앱에 넣습니다.
공공데이터포털 개발계정은 하루 1,000건 제한이라 실사용 트래픽을 감당할 수 없고,
연휴에 접속이 몰릴 때 앱이 멈추는 게 가장 나쁜 시나리오이기 때문이에요.

| 파일 | 내용 |
| --- | --- |
| `.cache/raw-*.json` | 전국 원본 응답(약국 25,351 + 병의원 78,903). git에 올리지 않음 |
| `src/data/regions.json` | 시군구 목록 + 동 인덱스(이름·중심좌표). 검색 자동완성에 사용 |
| `src/data/places/{i}.json` | 시군구 i 의 시설 목록. 선택한 지역만 `import()`로 로드 |
| `src/data/holidays.json` | 공휴일 목록 |

`sync:data`는 **전국을 받아 캐시에 넣고, 그중 `coverage.mjs` 범위만 골라서** 내보내요.
그래서 지역을 넓히거나 좁힐 때 API 쿼터를 다시 쓰지 않습니다.
공공데이터 자체를 최신으로 다시 받으려면 `npm run sync:data -- --refresh`.

`places/*.json`은 10만 건도 담을 수 있게 압축돼 있어요. 행을 객체 대신 배열로 쓰고,
동 이름·종별·운영시간 패턴은 파일별 사전으로 빼서 인덱스만 저장합니다(`scripts/emit.mjs`).
전국 기준 32MB → 17.5MB, 현재 6개 시군구는 1.1MB예요.

동 중심 좌표는 별도 행정구역 데이터셋 없이 **해당 동에 실제로 있는 시설들의 좌표 평균**으로 계산해요.
E-Gen 주소는 대부분 도로명이고 법정동이 끝 괄호에 들어있어서(`... 신장로 151 (덕풍동)`)
괄호 → 읍·면 토큰 → 옛 지번 순으로 훑습니다. 그래도 못 뽑으면 가장 가까운 동에 붙여요.

데이터를 갱신하려면 `npm run sync:data`를 다시 돌리고 재배포하면 돼요.
연휴 전에는 한 번 갱신하는 걸 권장해요.

### 공휴일 운영시간에 대해

E-Gen의 `dutyTime8`(공휴일)은 **약국 24% · 병의원 12%만** 등록돼 있어요.
누락이 아니라 나머지는 실제로 공휴일에 쉬기 때문이에요 — 이 앱이 걸러내려는 게 바로 그 차이입니다.
다만 "정보가 없다"와 "쉰다"는 다르므로, 해당 요일 값이 비면 휴무로 단정하지 않고
`정보 없음` 또는 `휴무일 수 있음`으로 표시해요.

## 앱인토스 정책 준수

의료 정보 서비스는 [오픈 정책](https://developers-apps-in-toss.toss.im/intro/guide.html)상 조건부 허용이에요.
이 앱은 아래를 지키도록 설계했어요.

- 공공데이터 기반 **조회만** 제공 — 예약·진료 연결·상담 기능 없음
- **순위·추천 없음** — 정렬 기준은 "선택한 동 중심에서 가까운 순" 하나뿐이고 화면에 명시
- 모든 기관을 **동일 기준으로 노출** — 노출 우대나 스폰서 슬롯 없음
- **데이터 출처를 화면 하단에 상시 표시**
- 병원으로부터 **어떠한 금전도 수취하지 않음**

## 빌드 / 배포

```bash
npm run build       # vite build + ait build → holiday-care.ait
```

생성된 `.ait` 파일을 앱인토스 콘솔 `앱 출시`에 업로드 → QR 테스트 → 검토 요청.

> `apps-in-toss.config.ts`의 `appName`은 콘솔 등록값과 **정확히** 일치해야 해요.
> 현재 값: `holiday-care`

## 알려진 제약

- 운영시간은 기관이 등록한 값이라 실제와 다를 수 있어요. 화면에 안내 문구를 넣어뒀어요.
- 공공데이터에 해당 요일 정보가 없으면 "휴무"로 단정하지 않고 "정보 없음"으로 표시해요.
- 위치 권한을 거부해도 동 이름 검색으로 모든 기능을 쓸 수 있어요.

## GitHub Pages 배포

같은 코드로 웹 버전도 만들어요. 미니앱은 도메인 루트에서 돌고 Pages 는 하위 경로에
올라가서 `base` 만 다릅니다.

```bash
npm run build        # 미니앱용 (base '/')      → holiday-care.ait
npm run build:web    # Pages 용 (base '/openpharm/') → dist/
node scripts/preview-web.mjs   # 배포본을 실제 경로 그대로 확인
```

`main` 에 푸시하면 `.github/workflows/deploy-pages.yml` 이 빌드해서 Pages 에 올려요.
저장소 `Settings > Pages > Source` 를 **GitHub Actions** 로 한 번만 바꿔주면 됩니다.

배포 주소: https://kjnewsletter.github.io/openpharm/

> 카카오맵을 웹에서도 쓰려면 카카오 콘솔 `앱 설정 > 플랫폼 > Web` 에
> `https://kjnewsletter.github.io` 를 추가해야 해요. 없으면 기본 지도로 나옵니다.
